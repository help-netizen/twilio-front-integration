9 · Close safely
The single ✕ asks before discarding a filled-in invoice — since the footer/CTA now scroll, this guards a long form against one stray tap.
The two changes that recover the most space + clicks:
BeforePinned header (title + Total) and pinned footer (Cancel/Create) fixed on screen; on a 375px phone that's ~120px of chrome that never moves — while you scroll a long form past it.
AfterOne scroll. Title and the Create button travel with the content; the running Total shows in the Totals section and again right above Create — where the decision is made.
BeforeOn the invoice view, Send / Resend / Void / Delete / Preview PDF hide inside a “More” kebab; Edit/Save are tiny icon buttons.
AfterThe one action you came for is a full-width violet button up top; Send / Preview are plain visible buttons; Void/Delete sit apart at the bottom. No hunting.
These are now in the set above — invoices list, collect-payment, and the void / close-safely confirmations. What’s left is implementation-level, not visual: one keyboard contract (the real input fix, replacing 5 mechanisms), one detail container across Job / Lead / Invoices, permission-gated actions, and the 3 latent bugs.
